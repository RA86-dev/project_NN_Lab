# Issue Reporting
If you find any issues, please report it! You can report issues through the Issues tab. When you have a issue, please create a issue document, and clearly include the following
- A image of what is happening (In this case, always show the logs)
- Open up the Developer Panel and go to Console, and copy the issues there too.
- What browser (nothing else).
## Privacy Notice
Please do not include PII (Personally Identifiable information)! This includes things such as:
- Names
- Emails
- Local File Paths
Its just there to protect you. If you have any issue, I will see what I can do to fix it!
